# UTM Dynamic Dashboard

## Setup

1. Keep Excel filename exactly:

master data final.xlsx

2. Ensure sheet name is:

Master Data

3. Upload repo to GitHub

4. Enable GitHub Pages:

Settings → Pages → Deploy from branch → main

5. Dashboard URL will be:

https://YOUR_USERNAME.github.io/REPO_NAME/

## Updating Dashboard

1. Replace old Excel file
2. Keep same filename
3. Push to GitHub
4. Dashboard updates automatically
